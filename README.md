# Coronary Stenosis Detector Model

Final project materials for coronary stenosis classification from angiogram images using PyTorch and EfficientNet-B4.

## Files

- `Coronary Artery Detector.ipynb`: data preparation, training, evaluation, and inference notebook.
- Four PDF documents: project presentation, dataset information, manuscript, and appendix.

## Running the notebook

Open the notebook in Jupyter or Google Colab. The first cell installs dependencies. Set the `ROBOFLOW_API_KEY` environment variable before running the dataset download cell. Use your own Roboflow credentials.

Trained model weight files are not included in this archive.
